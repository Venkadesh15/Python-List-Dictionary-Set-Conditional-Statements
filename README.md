# 🐍 Python Lists, Dictionaries, Sets & Conditional Statements

## 📌 Project Overview

A beginner-friendly Python assignment covering data structures, operators, and conditional statements.

## 📚 Topics Covered

- 📋 Lists and list operations
- 📚 Dictionaries and key-value pairs
- 🔤 Sets and set operations
- ➕ Comparison and logical operators
- 🔀 `if`, `elif`, and `else`
- ⌨️ User input and validation
- 🧮 Built-in functions

## 🎯 Assignment Tasks

### 📋 Lists

- Create age and name lists
- Add, insert, remove, and extend list elements
- Sort ages in descending order
- Find the maximum, minimum, and sum of the ages
- Access elements using indexes and slicing

### 📚 Dictionaries

- Create a dictionary of student marks
- Access a student's mark
- Add and update student records
- Display keys, values, and key-value pairs

### 🔤 Sets

- Create a set and observe how it handles duplicate values
- Understand why sets do not support indexing
- Perform union and intersection operations

### 🎯 Conditional Statements

Enter a score from **0 to 10** to see its performance category:

| Score | Category |
|---|---|
| Greater than 7 | 🌟 Above Average |
| 4 to 7, inclusive | 😊 Average |
| Less than 4 | 📚 Below Average |

The program also checks for scores outside the valid range.
