🐍 Python List, Dictionary, Set & Conditional Statements
📌 Project Overview

This project is a beginner-level Python assignment covering basic data structures, operators, and conditional statements.

📚 Topics Covered
📋 Lists
📚 Dictionaries
🔤 Sets
➕ Operators
🔀 if, elif, else
⌨️ User input
🧮 Built-in functions

🎯 Assignment Tasks
📋 Lists
Create age and name lists
Add and remove elements
Insert and extend elements
Sort ages in descending order
Find maximum, minimum, and sum
Access elements using indexes and slicing
📚 Dictionaries
Create a student marks dictionary
Access student marks
Add and update student information
Display keys, values, and key-value pairs
🔤 Sets
Create a set and remove duplicates
Understand why sets do not support indexing
Perform union and intersection operations
🎯 Conditional Statements

Accept a score from 0 to 10 and display the performance category:

Score	Category
Greater than 7	🌟 Above Average
4 to 7	😊 Average
Less than 4	📚 Below Average

The program also checks for invalid scores.

▶️ How to Run

Make sure Python is installed.

python --version


Run the program:

python Python_List_Dictionary_Set_Conditional_Statements.py


For macOS/Linux:

python3 Python_List_Dictionary_Set_Conditional_Statements.py
